# AI DAST 학습 위키 운영 규칙

이 디렉터리는 AI DAST를 공부하기 위한 LLM 관리 위키다. `README.md`, `docs/`, `src/`, `tests/`, `WebUI/`의 기존 파일은 원본 자료로 취급한다. 위키 작업을 위해 원본을 수정하지 않는다.

## 자료 반영

1. 질문이나 학습 주제에 맞는 원본 문서와 현재 코드를 읽는다. 설계 문서와 구현이 다르면 현재 코드와 테스트를 우선 확인하고 차이를 명시한다.
2. 위키의 모든 중요한 사실에는 원본 파일로 가는 상대 링크를 붙인다. 실행 동작을 설명할 때는 가능하면 코드 또는 테스트도 연결한다.
3. 사실, 해석, 미확인 사항을 구분한다. 확인하지 않은 동작을 확정적으로 쓰지 않는다.
4. 새 내용을 기존 페이지에 통합하고 관련 페이지의 링크를 갱신한다. 중복 페이지는 만들지 않는다.
5. `index.md`를 갱신하고 `log.md`에 날짜, 작업, 변경 페이지, 확인한 원본을 기록한다.

## 질문에 답하기

- 먼저 `index.md`에서 관련 페이지를 찾고, 답을 작성하기 전에 원본의 현재 상태를 확인한다.
- 위키와 원본이 충돌하면 원본을 다시 확인하고 위키를 수정한다.
- 유용한 비교나 설명은 적절한 위키 페이지에 반영한다.
- 학습용 질의는 읽기 전용으로 수행한다. 실제 대상에 대한 네트워크 스캔이나 공격 실행은 학습 질문만으로 시작하지 않는다.

## 점검

주기적으로 깨진 링크, 원본 변경으로 오래된 설명, 서로 충돌하는 주장, 출처 없는 사실, 연결되지 않은 페이지를 점검한다. 문제를 고친 뒤 `log.md`에 남긴다.

## 페이지 형식

- 한국어로 간결하게 쓰고, 제목 아래에 이 페이지가 답하는 질문을 적는다.
- 원본 근거를 해당 주장 가까이에 링크한다.
- 마지막에 `확인할 질문`을 두어 다음 학습으로 연결한다.
- 인증 정보, 쿠키, 토큰, 실제 스캔 결과의 민감한 내용은 위키에 복사하지 않는다.
